## III. Lưu ý & Quy tắc nghiệp vụ

{% hint style="warning" %}
### Lưu ý quan trọng

1. Danh sách mặc định được sắp xếp theo thời gian tạo giảm dần; có thể dùng filter **Sort By** để sắp xếp lại.
2. Khi chọn **Reset**, toàn bộ điều kiện tìm kiếm hiện tại sẽ bị xóa.
3. Màn hình chi tiết Item Set có thể bao gồm thông tin cơ bản và danh sách câu hỏi thuộc Item Set.
4. Chức năng **Preview** chỉ dùng để xem trước cách câu hỏi hiển thị, không dùng để chỉnh sửa nội dung câu hỏi.
5. Nếu câu hỏi đã được thêm vào Test/Quiz/Case Study thì không thể xóa câu hỏi đó khỏi Item Set.
6. Không thể xóa Item Set chứa câu hỏi đã được thêm vào Test/Quiz/Case Study.
{% endhint %}

{% hint style="info" %}
### Mẹo sử dụng

1. Nên kiểm tra câu hỏi bằng chức năng **Preview** trước khi sử dụng trong Test/Quiz hoặc Case Study.
2. Nên dùng **Reset** khi muốn quay lại danh sách mặc định sau nhiều lần tìm kiếm.
{% endhint %}

## IV. Các lỗi thường gặp & Hướng dẫn xử lý

| Lỗi / Tình huống                            | Nguyên nhân                                              | Cách xử lý                                              |
| ------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------- |
| Không tìm thấy dữ liệu                      | Điều kiện tìm kiếm chưa đúng hoặc quá hẹp                | Kiểm tra lại bộ lọc, sau đó chọn Search lại             |
| Danh sách không hiển thị dữ liệu mới nhất   | Danh sách đang bị lọc theo điều kiện trước đó            | Chọn Reset để xóa bộ lọc                                |
| Không lưu được Item Set                     | Chưa nhập đủ trường bắt buộc hoặc tên Item Set bị trùng  | Nhập đủ các trường (\*) và đặt tên không trùng rồi Save |
| Không upload được Exhibit/Time Value Tables | File vượt quá dung lượng cho phép                        | Đảm bảo file ≤ 500MB trước khi tải lên                  |
| Không xóa được câu hỏi khỏi Item Set        | Câu hỏi đã được thêm vào Test/Quiz/Case Study            | Gỡ câu hỏi khỏi Test/Quiz/Case Study trước khi xóa      |
| Không xóa được Item Set                     | Item Set chứa câu hỏi đã dùng trong Test/Quiz/Case Study | Gỡ các câu hỏi liên quan trước khi xóa Item Set         |
