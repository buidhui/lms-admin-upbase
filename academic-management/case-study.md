## III. Lưu ý & Quy tắc nghiệp vụ

{% hint style="warning" %}
### Lưu ý quan trọng

1. Người dùng cần có quyền tương ứng để xem, tạo mới hoặc chỉnh sửa Case Study.
2. Danh sách Case Study mặc định hiển thị theo thời gian tạo giảm dần; có thể dùng filter **Sort By** để sắp xếp lại.
3. Các trường có dấu **(\*)** là trường bắt buộc, cần nhập đầy đủ trước khi lưu.
4. Case Study có thể bao gồm một hoặc nhiều Item Set.
5. Sau khi tạo mới và bấm **Save**, hệ thống mới hiển thị khu vực danh sách Item Set để thêm Item Set.
6. Khi thêm Item Set, người dùng cần chọn Item Set có sẵn trong hệ thống.
7. Khi chỉnh sửa thứ tự Item Set: thứ tự phải là số nguyên dương, không trùng nhau, và thứ tự lớn nhất ≤ tổng số Item Set thuộc Case Study.
8. Sau khi bấm **Save** tại màn hình Reorder, danh sách Item Set sẽ hiển thị theo thứ tự mới.
{% endhint %}

{% hint style="info" %}
### Mẹo sử dụng

1. Nên đặt tên Case Study rõ ràng và nhập mô tả ngắn gọn nhưng đủ ý để người khác hiểu bối cảnh.
2. Nên chuẩn bị sẵn các Item Set trước khi tạo hoặc cấu hình Case Study.
3. Nên kiểm tra lại danh sách Item Set sau khi thêm để đảm bảo đúng nội dung cần sử dụng.
4. Khi Case Study có nhiều Item Set, nên dùng chức năng **Reorder** để kiểm soát thứ tự thay vì xóa và thêm lại.
5. Nên dùng bộ lọc **Case Study Name** hoặc khoảng thời gian để tìm nhanh khi dữ liệu nhiều.
{% endhint %}

| Lỗi / Tình huống                        | Nguyên nhân                                                                  | Cách xử lý                                                                   |
| --------------------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Không thể lưu Case Study                | Chưa nhập đủ các trường bắt buộc có dấu (\*)                                 | Kiểm tra và nhập đầy đủ các trường bắt buộc rồi bấm Save                     |
| Không tìm thấy Case Study               | Sai điều kiện lọc tìm kiếm                                                   | Kiểm tra lại điều kiện tìm kiếm, bấm Reset để về danh sách mặc định          |
| Chưa thấy khu vực danh sách Item Set    | Chưa bấm Save sau khi nhập thông tin Case Study                              | Bấm Save để hệ thống hiển thị khu vực danh sách Item Set                     |
| Không thêm được Item Set vào Case Study | Hệ thống chưa có Item Set để lựa chọn                                        | Tạo/chuẩn bị Item Set trong Question Bank trước khi thêm vào Case Study      |
| Lưu Reorder thất bại                    | Thứ tự trùng nhau, không phải số nguyên dương, hoặc lớn hơn tổng số Item Set | Nhập lại thứ tự đúng quy tắc (số nguyên dương, không trùng, ≤ tổng Item Set) |
| Không thực hiện được thao tác tạo/sửa   | Tài khoản chưa được cấp quyền tương ứng                                      | Liên hệ Admin để được cấp quyền tạo mới/chỉnh sửa Case Study                 |
