## III. Lưu ý & Quy tắc nghiệp vụ

{% hint style="warning" %}
### Lưu ý quan trọng

1. Kết quả chỉ hiển thị sau khi Mentor phụ trách đã **Finish** chấm bài.
2. Học viên không phân biệt được kết quả chấm bởi AI hay Mentor; kết quả hiển thị như chấm tay thông thường.
3. Chỉ các Grading Files được SX bật **"Show to Students"** mới hiển thị cho học viên.
4. File dưới 20MB: xem trước trực tiếp; file trên 20MB: tải về để xem.
{% endhint %}

{% hint style="info" %}
### Mẹo sử dụng

1. Đọc kỹ nhận xét (Comment) ở từng câu để hiểu điểm mạnh/điểm cần cải thiện.
2. Tham khảo Rubric/Other Files (nếu có) để biết tiêu chí chấm điểm.
{% endhint %}

## IV. Các lỗi thường gặp & Hướng dẫn xử lý

| Lỗi / Tình huống               | Nguyên nhân                              | Cách xử lý                                         |
| ------------------------------ | ---------------------------------------- | -------------------------------------------------- |
| Chưa thấy kết quả bài Test     | Mentor phụ trách chưa Finish chấm bài    | Chờ Mentor hoàn tất; liên hệ Mentor/CX nếu quá hạn |
| Không thấy mục "Grading Files" | SX không bật "Show to Students" cho file | Đây là cấu hình của SX; liên hệ CX nếu cần file    |
| Không xem trước được file      | File vượt 20MB                           | Tải file về máy để xem                             |
| Không mở được file đính kèm    | Định dạng/đường truyền                   | Tải lại file hoặc liên hệ kênh hỗ trợ nội bộ       |
