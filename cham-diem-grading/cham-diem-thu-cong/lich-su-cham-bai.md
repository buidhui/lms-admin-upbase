## I. Thông tin chung

{% hint style="info" %}
**Dành cho:** Mentor, Mentor chính

**Đường dẫn:** Màn danh sách bài test → button 3 chấm → Grading History
{% endhint %}

{% hint style="warning" %}
#### Điều kiện tiên quyết

* User đăng nhập thành công vào hệ thống.
* Bài đã được chấm điểm.
{% endhint %}
