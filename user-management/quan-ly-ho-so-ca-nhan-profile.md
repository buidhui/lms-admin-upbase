# Hồ sơ cá nhân (My Profile)

## I. Thông tin chung

{% hint style="info" %}
**Dành cho:** UpLMS Operator

**Đường dẫn:** [https://uplms-ops.upbase.asia](https://uplms-ops.upbase.asia/)
{% endhint %}

{% hint style="warning" %}
#### Điều kiện tiên quyết

* Đã có tài khoản và được cấp quyền truy cập hệ thống UpLMS Ops.
* Tài khoản có quyền tương ứng với từng chức năng cần thực hiện.
{% endhint %}

## II. Hướng dẫn chi tiết

<details>

<summary>Đăng nhập &#x26; Đăng xuất</summary>

{% stepper %}
{% step %}
**Truy cập hệ thống UpLMS Ops**

Mở trình duyệt và truy cập đường dẫn hệ thống UpLMS Ops: [https://ops.staging.upbase.asia/](https://ops.staging.upbase.asia/)
{% endstep %}

{% step %}
**Đăng nhập**

Nhập Username và Password vào trường tương ứng, chọn Sign In để tiến hành đăng nhập vào hệ thống UpLMS Ops

<figure><img src="../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Đăng xuất**

Chọn vào biểu tượng Đăng xuất ở góc dưới bên trái màn hình để đăng xuất khỏi hệ thống UpLMS Ops

<figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

</details>

<details>

<summary>View Profile Details</summary>

{% stepper %}
{% step %}
**Truy cập My Profile**

Tại góc dưới bên trái màn hình, chọn vào avatar và chọn "**My profile**".

<figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Xem thông tin chung Truy cập tab Overview**

Truy cập tab Overview, hệ thống hiển thị thông tin của tài khoản, bao gồm:

* Code
* Fullname
* Username
* Email
* Số điện thoại
* Role
* Trạng thái
* Thời gian cập nhật

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Xem chi tiết quyền của tài khoản**

Truy cập tab **My role**, chọn vào từng nhóm quyền để xem chi tiết.

<figure><img src="../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

</details>

<details>

<summary>Reset Password</summary>

**Cách 1: Truy cập User Management**

Áp dụng cho người dùng CÓ quyền edit thông tin Staffs

{% stepper %}
{% step %}
**Truy cập danh sách Staffs**
{% endstep %}

{% step %}
**Chọn Reset password**

Tìm tài khoản cần Thay đổi mật khẩu **→**&#x41;ction **→** Reset password.

<figure><img src="../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Xác nhận Reset**

<figure><img src="../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

**Cách 2: Sử dụng tính năng Quên mật khẩu**

Áp dụng cho người dùng KHÔNG có quyền chỉnh sửa thông tin Staffs

{% stepper %}
{% step %}
**Chọn Forgot Password**

Tại màn hình Đăng nhập chọn Forgot Password

<figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Nhập email đăng ký**

Nhập thông tin email đăng ký tài khoản và nhấn "**Send**".

<figure><img src="../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Xác thực mã code**

Truy cập email nhận thông tin mã code và chọn **Verify**.

<figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Nhập mật khẩu mới**

Nhập mật khẩu mới và chọn **Submit** để hoàn tất đổi mật khẩu.
{% endstep %}
{% endstepper %}

</details>

<details>

<summary>Edit Email</summary>

{% stepper %}
{% step %}
**Truy cập danh sách Staffs**
{% endstep %}

{% step %}
**Chọn Edit Email**

Tìm tài khoản cần chỉnh sửa Email **→** Action **→** Edit Email

<figure><img src="../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Nhập Email mới và OTP**

Nhập Email mới và nhập OTP được gửi tới Email đó, sau đó chọn **Save** để hoàn tất thay đổi Email.

<figure><img src="../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

</details>
