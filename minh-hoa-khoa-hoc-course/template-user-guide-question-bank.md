## II. Hướng dẫn chi tiết

<details>

<summary>Xem danh sách &#x26; chi tiết</summary>

{% stepper %}
{% step %}
**Vào "Question Bank" → chọn tab "Item Set"**

<figure><img src="../.gitbook/assets/image (958).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Người dùng có thể tìm kiếm câu hỏi bằng cách sử dụng bộ lọc**

* Người dùng có thể điền Item Set Name, chọn Sort By, From/To Date sau đó bấm "Search" để hiển thị kết quả mong muốn.
* Khi muốn xóa bộ lọc, người dùng chỉ việc bấm bấm "Reset".

<figure><img src="../.gitbook/assets/image (957).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Click vào tên Item Set để xem chi tiết nội dung**

<figure><img src="../.gitbook/assets/image (959).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Tại mục Question List, chọn "Create Question" để tạo câu hỏi thuộc Item Set**

<figure><img src="../.gitbook/assets/image (962).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Tại mục Question List, chọn Action → Preview để xem trước câu hỏi sẽ hiển thị thế nào trên giao diện học viên**
